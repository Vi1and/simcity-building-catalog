# Городской архив SimCity BuildIt

Статический каталог зданий из двух актуальных локальных источников:

- «Абонемент мэра»;
- «Другие здания» — непостоянные объекты из полного каталога и проверенные региональные Hot Spot-здания.
- «Тематические» — 23 пересекающиеся подборки по регионам и мотивам: Япония, пустыня, вода, аттракционы, зима, природа, космос, Альфа-город, замки, тропики, транспорт, мосты, спорт и отдельные европейские страны и регионы.
- «Популярные» — 38 объектов, отмеченных как популярные в актуальной таблице каталога.

У зданий доступны дневные, ночные и событийные фотографии, если они есть в локальной Wiki-галерее. Служебные скриншоты меню, акций и ошибок при экспорте отбрасываются. Тёмная тема включена по умолчанию; выбор светлой темы сохраняется в браузере.

Избранное хранится только в браузере пользователя (`localStorage`). На телефонах и планшетах навигация и действия «Копировать / Очистить / Вставить» закреплены у нижнего края; на телефоне можно выбрать одну или две карточки в ряду. Плавающие кнопки избранного и возврата к фильтрам остаются доступными при прокрутке, а в избранном есть кнопки возврата в каталог сверху и снизу. Если поиск находит здание в другом разделе, каталог предлагает перейти туда одним нажатием. Карточки и галерея показывают текущий номер фотографии и общее количество. Сервер и база данных не требуются.

Прозрачная hero-иллюстрация города создана встроенным ImageGen и хранится в адаптивных WebP-файлах `public/hero-city-v1.webp`, `public/hero-city-v1-640.webp` и `public/hero-city-v1-placeholder.webp`. В карточках особые признаки расположены под названием, а в подробном окне размер, бонус, специализация и область действия выделены отдельными цветными блоками.

## Локальный запуск

```powershell
npm install
npm run dev
```

После запуска откройте **http://localhost:5173/**. Команду нужно выполнять из папки `simcity-building-catalog`.

Чтобы проверить уже собранную production-версию:

```powershell
npm run build
npm run preview
```

Vite покажет точный адрес preview в терминале (обычно **http://localhost:4173/**). После изменения исходников сначала снова выполните `npm run build`, иначе preview будет показывать старую сборку.

## Обновление данных

По умолчанию экспортёр читает данные из `D:\Obsidian\MAIND`:

```powershell
npm run data:refresh
```

Другие пути можно передать явно:

```powershell
python scripts/export_catalog.py --scripts "D:\path\to\Scripts" --images "D:\path\to\images"
```

Скрипт создаёт `src/data/catalog.json` и копирует используемые изображения в `public/buildings`. Если локальная галерея ошибочно указывает на VK-снимок, но рядом есть оригинал SimCity BuildIt Wiki, экспортёр предпочитает Wiki-версию.

Дополнительные галереи зданий Абонемента мэра синхронизируются из проверенных Wiki-страниц и локальной базы сообщества командой `python scripts/sync_mayor_fandom_galleries.py --apply`. Результат сохраняется в `scripts/mayor_fandom_images.json`, а изображения — в оптимизированном WebP-формате в `scripts/manual_images`.

Список постоянных Hot Spot-зданий и признаки «популярное / редкое» хранятся в `scripts/featured_buildings.json`; отметки «популярное» синхронизированы с актуальной Google-таблицей. Шесть Hot Spot-карточек, которых нет в исходном JSON или у которых не указан игровой код, описаны в `scripts/manual_buildings.json`; их проверенные изображения лежат в `scripts/manual_images`. Неизвестные коды остаются пустыми — технические числа вместо них не придумываются.

## Проверка

```powershell
npm run test:all
npm run build
```

Первый запуск E2E-тестов также требует локальный Chromium:

```powershell
npx playwright install chromium
```

## Размещение на Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: 22 или новее

После публикации сайт работает как обычная статическая страница и не «засыпает».
